## What it does

`main.py` (Python 3, standard library only) writes one original one-line
joke about office life to `/output/entry.txt`.

## Run

```sh
python3 main.py
```

## The line

> The coffee machine broke, so now we just stare at each other and call it a stand-up meeting.

92 characters, one line, under the 199-character gate.
